Pour l'équipe

Règles communes

  • QuandLe loader de démarrage ne joue qu'à la première page de la session (drapeau en sessionStorage). Les pages suivantes utilisent le loader de transition.
  • Prêt« Contenu prêt » = DOMContentLoaded + document.fonts.ready, plafonné à 2,5 s pour les polices. On n'attend jamais la carte Leaflet : elle charge derrière.
  • AccélérationSi le contenu est prêt pendant la construction, les animations restantes passent à ×2 (updatePlaybackRate). On ne coupe jamais net : le logo finit toujours entier.
  • AttenteConstruction finie mais contenu pas prêt : seul le voyant respire (une seule boucle). Après 3 s, une ligne dit « Réseau lent ».
  • Sans JSLe loader est masqué par défaut et n'apparaît que si le script ajoute class="js" sur <html>. Sans JS, l'accueil s'affiche directement.
  • PoidsSVG inline + CSS critique + ~2 Ko de JS dans le <head>. Web Animations API native, aucune librairie. Le nom est en tracés SVG, il n'attend pas la police.
  • TransitionsN'apparaissent qu'après 150 ms (rien ne clignote sur une page rapide) et restent visibles au moins 300 ms une fois apparues.
